# Netflix Data Analytics

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Titles Dataset to uncover content trends, genre distribution, audience preferences, and global content insights.

## Objectives
- Analyze Movies vs TV Shows distribution
- Study content growth trends
- Explore genre popularity
- Perform country-wise content analysis
- Analyze content ratings and audience segmentation
- Generate business insights

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- WordCloud
- Jupyter Notebook

## Dataset Features
- Show ID
- Type
- Title
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre

## Key Insights
- Movies dominate Netflix's catalog
- Significant growth observed between 2016–2020
- International Movies are among the most popular genres
- United States and India contribute the highest number of titles
- Netflix primarily targets mature and young-adult audiences
